# Markdownスタイルガイド

Markdownフォーマットの包括的なガイドです。

## ヘッダー

`#`を使用してヘッダーを作成できます：

# H1ヘッダー
## H2ヘッダー
### H3ヘッダー

## テキストフォーマット

- **太字テキスト**は`**text**`で作成
- *斜体テキスト*は`*text*`で作成
- ~~取り消し線~~は`~~text~~`で作成

## リスト

順序なしリスト:
- 項目1
- 項目2
- 項目3

順序付きリスト:
1. 最初の項目
2. 2番目の項目
3. 3番目の項目

## コード

インラインコード: `const x = 10;`

コードブロック:
```javascript
function hello() {
  console.log("こんにちは、世界！");
}
```
