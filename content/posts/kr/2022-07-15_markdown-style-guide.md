# 마크다운 스타일 가이드

마크다운 포매팅에 대한 완벽한 가이드입니다.

## 헤더

`#`를 사용하여 헤더를 만들 수 있습니다:

# H1 헤더
## H2 헤더
### H3 헤더

## 텍스트 포매팅

- **굵은 텍스트**는 `**텍스트**`로 작성
- *기울임 텍스트*는 `*텍스트*`로 작성
- ~~취소선~~은 `~~텍스트~~`로 작성

## 목록

순서 없는 목록:
- 항목 1
- 항목 2
- 항목 3

순서 있는 목록:
1. 첫 번째 항목
2. 두 번째 항목
3. 세 번째 항목

## 코드

인라인 코드: `const x = 10;`

코드 블록:
```javascript
function hello() {
  console.log("안녕하세요, 세계!");
}
```
