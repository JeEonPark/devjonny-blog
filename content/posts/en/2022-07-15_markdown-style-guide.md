# Markdown Style Guide

Here's a comprehensive guide to markdown formatting.

## Headers

You can use `#` for headers:

# H1 Header
## H2 Header
### H3 Header

## Text Formatting

- **Bold text** with `**text**`
- *Italic text* with `*text*`
- ~~Strikethrough~~ with `~~text~~`

## Lists

Unordered lists:
- Item 1
- Item 2
- Item 3

Ordered lists:
1. First item
2. Second item
3. Third item

## Code

Inline code: `const x = 10;`

Code blocks:
```javascript
function hello() {
  console.log("Hello, World!");
}
```

## Links and Images

[Link to Google](https://google.com)

![Alt text for image](/path/to/image.jpg)

## Blockquotes

> This is a blockquote
> It can span multiple lines

## Conclusion

Markdown is a simple and powerful way to format text!
